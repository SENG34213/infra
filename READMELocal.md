# Gaming Castle Infrastructure

## Requirements

- Docker
- Docker Compose

## Start infrastructure

docker compose up -d

## Stop infrastructure

docker compose down

## PostgreSQL

Host: localhost
Port: 5432
User: gc_admin

gamingcastle_users
